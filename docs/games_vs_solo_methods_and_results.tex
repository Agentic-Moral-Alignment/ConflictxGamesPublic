\title{Values in Company: How Multi-Agent Games Elicit Different\\
       Value Preferences than Solo Evaluation}
\author{ConflictxGame programme report}

\begin{abstract}
\noindent
We evaluate ten language models on 150 balanced helpful/harmless/honest (HHH)
value conflicts, each posed twice: once to a model deciding alone, and once to a
model occupying one seat of a two-player simultaneous-move game. Two findings
dominate. First, \emph{elicitation format} moves value preferences more than any
manipulation we applied: moving from forced choice to free text raises the
helpfulness win-rate by between $+0.19$ and $+0.79$ in every one of the ten
models. Second, conditional on format, \emph{placing the model in a game shifts
it toward harmlessness and away from helpfulness}, significantly in 31 of 40
model--arm--format cells for harmlessness against helpfulness and in 0 cells in
the opposite direction. A three-way decomposition localises the cause: the shift
appears entirely in the step from solo to a single game round, and not at all in
the step from one-shot to repeated framing. What the game adds is a counterpart,
not a future. Explicit stake framings and an HHH system prompt move almost
nothing, and we report an explicit ceiling audit so those nulls are not read as
stronger than the data supports.
\end{abstract}

\section{The question}

A model asked to resolve a value conflict alone is answering a question about
its dispositions. A model asked to resolve the same conflict while another agent
independently decides something that jointly determines the outcome is doing
something else: it is acting under uncertainty about a counterpart. Deployment
increasingly looks like the second case. This programme asks whether the two
elicitations give the same answer, and if not, what specifically about the game
is responsible.

\section{Provenance}

The pipeline is a fork of \textbf{ConflictScope} (Liu et al., 2025,
\texttt{arXiv:2509.25369}), an MIT-licensed framework for measuring value
preferences through generated conflict scenarios. The upstream project is
dyadic: one model, one scenario, one choice. This fork, ConflictxGame, retains
the upstream generation-and-filtering machinery and the upstream solo evaluation
path unchanged, and adds a multi-agent game path alongside it. All solo results
reported here come from the upstream-derived code; the game results come from
the additions.

\section{Values and what counts as a conflict}

The value set (\texttt{HHH\_new}) contains three values, defined verbatim as:

\begin{quote}\small
\val{helpfulness} --- being as helpful as possible to the people one is dealing
with (fulfilling their expressed requests and stated goals promptly and
effectively, as they have stated them, rather than substituting one's own
judgment of what is best for them).

\val{harmlessness} --- being as harmless as possible (avoiding causing physical,
emotional, financial, or social harm to anyone, and not encouraging unethical
behavior).

\val{honesty} --- being as honest as possible (not deceiving others, and not
withholding information that would materially change their understanding of the
situation).
\end{quote}

A scenario instantiates a conflict between exactly two of these. Every action
available to a decision-maker is tagged with the value it favours, and we
verified across all 150 evaluated seats that both of a seat's action tags fall
inside that seat's own value pair --- no seat offers an escape action favouring
a third value.

\section{Corpus generation}

Both corpora were generated by \textbf{Claude Sonnet 5} at temperature 1.0 with
seed 0, filtered by a \textbf{GPT-5.6 Luna} judge, and deduplicated by sentence
embedding at a cosine threshold of 0.8. Generation used the \texttt{paper}
prompt style with \texttt{generation\_guidance: none}, i.e.\ no steering toward
particular content.

\subsection{The game corpus}

Generation targeted a single structural cell: \texttt{simultaneous\_n2\_a2x2}
--- two players, two actions each, moving simultaneously. Of \textbf{503}
generated scenarios, \textbf{117} survived the filter. Each scenario seats two
players; the focal seat is always an assistant
(\texttt{assistant\_seat\_prob: 1.0}), and the counterpart may be a human or a
second assistant.

\subsection{The solo corpus}

The solo corpus was generated by the same model, judge and value set, in the
upstream dyadic format: \textbf{1{,}187} generated, \textbf{162} kept, split
59/52/51 across the three value pairs.

\subsection{A caveat that matters for interpretation}

\textbf{The two corpora share no scenarios.} Their \texttt{scenario\_id} sets
intersect in exactly zero elements (503 game ids, 1{,}187 solo ids, overlap 0).
The solo and game conditions are therefore \emph{independent samples from the
same generator under the same value definitions}, not the same situations
re-framed. Every domain contrast in this report is a between-corpus comparison.
We consider this the single largest threat to the causal reading of the game
effect and return to it in Section~\ref{sec:limits}.

\section{Balanced selection: the unit is a seat}
\label{sec:selection}

The evaluated unit is a \textbf{scenario-seat}, not a scenario. One scenario
seats two players, each carrying its own value pair, so a scenario may
contribute one seat, two, or none. Selection takes exactly
$\texttt{pair\_limit} = 50$ seats per value pair, ranking candidates by
\[
  \mathrm{sha256}\bigl(\texttt{seed} \mid \texttt{scenario\_id} \mid \texttt{seat}\bigr),
  \qquad \texttt{seed} = 0,
\]
and taking the first 50. The ranking is deterministic and content-independent,
so the same 150 seats are selected for every model and every arm.

That yields \textbf{150 seats drawn from 102 distinct scenarios} --- 54
scenarios contributing one seat and 48 contributing two --- balanced at exactly
50 seats per pair. All 150 focal seats are assistant seats. We verified the
exported seat set is identical to the seat set present in the results of every
game arm, across models and formats.

\section{Evaluation design}

\subsection{Domains and formats}

Each model was evaluated in four cells, crossing domain with elicitation format:

\begin{center}\small
\begin{tabular}{lll}
\toprule
 & \textbf{forced choice} & \textbf{free text} \\
\midrule
\textbf{solo} & MCQ: pick A or B & chat with a simulated user, judge-scored \\
\textbf{game} & MCQ over the action menu & open-ended response, judge-scored \\
\bottomrule
\end{tabular}
\end{center}

Format matching is not cosmetic. Because format turns out to be the largest
effect in the study (Section~\ref{sec:format}), comparing ``solo'' to ``game''
without holding format fixed would confound the two. Every domain contrast below
is run twice, forced-choice against forced-choice and free-text against
free-text.

\subsection{Arms}

Within each cell we ran, holding the scenario and options fixed:

\begin{itemize}\itemsep2pt
\item \textbf{baseline} and \textbf{HHH-steered} (a system prompt instructing
      helpfulness, harmlessness and honesty);
\item \textbf{stake} arms framing the decision as mattering for
      \emph{payoff}, \emph{alignment}, or \emph{usefulness}, each in a concrete
      and an abstract phrasing;
\item \textbf{observability} arms: told observed, told unobserved, and a plain
      baseline with no mention of who can see;
\item \textbf{memory-state probes}: every seat evaluated once per distinct
      \textsc{mem-1} state --- \texttt{fresh} (no history), and each possible
      previous-round joint outcome, recorded here as how many players took the
      value-favouring action (\texttt{none}, \texttt{one}, \texttt{both}).
\end{itemize}

All evaluations ran at temperature 0 with seed 0.

\subsection{Models}

Ten models completed the programme: Gemma 4 31B IT, Gemma 4 26B A4B, Gemma 3
27B, Gemma 3 12B, GPT-OSS 120B, GPT-OSS 20B, Llama 3.3 70B, Llama 4 Maverick,
Qwen 3 235B A22B, and Qwen 3 32B. Open-weight models were served through the
institutional gateway or OpenRouter; the simulated user and the judge always ran on
a paid OpenAI endpoint so that judging was never performed by the model under
test.

\subsection{Refusals}

Responses that refuse or fail to parse are excluded from rates and counted
separately, never imputed. A model that declines the hardest scenarios would
otherwise appear decisive on an easier subset than its peers are scored on. Two
models required this: GPT-OSS 120B answered 91 of 100 solo forced-choice
decisions, and GPT-OSS 20B 76 of 100.

\section{Analysis}

For each cell we report the \emph{win rate} of a value: the share of contests
involving that value in which the action favouring it was chosen. Level
uncertainty uses Wilson score intervals; differences of proportions use 95\%
Wald intervals. Throughout, an asterisk marks an interval excluding zero. We
report per-cell intervals rather than a single omnibus test because the
interesting structure is where effects appear, not whether any exist.

\paragraph{The effect is strongly format-dependent.}
For harmlessness against helpfulness, the free-text contrast is significant in

solo forced choice. Models that disagree markedly when alone converge when
placed in a game.

\subsection{It is the counterpart, not the future}

The game differs from solo evaluation in two ways at once: a counterpart exists,
and the interaction is framed as ongoing. These can be separated, because three
conditions all have empty history and are therefore directly comparable: solo;
a single one-shot round; and the first round of the repeated framing evaluated
at its fresh-start state.

\begin{table}[h]\centering\small

The whole effect lives in the first step. Solo to single round moves harmlessness
$+0.20$ and honesty $-0.13$; single round to first round moves harmlessness
$0.00$ and honesty $-0.02$. \textbf{Adding a counterpart does the work; adding a
future does nothing measurable.} Whatever the game elicits, it is not
forward-looking strategic reasoning about repeated play --- it is a response to
the presence of another decision-maker.

\subsection{Observability modulates the copying, not the level}

The observability arms tell the agent its decision either will or will not be
revealed. The informative quantity is the \emph{slope}: how strongly the agent
copies the remembered behaviour of its counterpart.

\begin{center}\small
\begin{tabular}{lrr}
\toprule
Arm & mean slope & significant \\
\midrule
No mention & $+0.191$ & 21/30 \\
Told unobserved & $+0.150$ & 14/30 \\
Told observed & $+0.137$ & 12/30 \\
\bottomrule
\end{tabular}
\end{center}

Copying is positive in all three arms. The naive prediction --- that conformity
should weaken when nobody is watching --- is not what we see: the
\emph{told-unobserved} slope ($+0.150$) is not below the \emph{told-observed}
slope ($+0.137$). Instead, both visibility arms sit below the arm that says
nothing at all. Raising the topic of who can see appears to dampen copying
regardless of the answer given. We flag this as a suggestive pattern rather than
a result: the arm-to-arm differences are small relative to their scatter, and
we did not power the study to separate them.

\paragraph{Stakes.} Framing the decision as mattering for payoff, alignment or
usefulness moves essentially nothing, in either domain:

At $\alpha = 0.05$ one expects roughly 3 of 60 and 2 of 48 significant cells by
chance; the observed counts are at or near that.

\paragraph{Steering.} An HHH system prompt likewise moves little: mean deltas of
$+0.006$ (solo forced), $-0.001$ (solo chat), $+0.028$ (game forced) and
$+0.042$ (game open), with 1--5 of 30 cells significant in each condition. The
system prompt is weaker than the format of the question it precedes.

\paragraph{Ceiling audit.} A null is only informative if the measurement had
room to move. Of the 120 baseline cells in Table~\ref{tab:levels}, \textbf{10
sit within 0.10 of a bound}: five in game forced choice (GPT-OSS 120B at
\val{harmless} 0.95 and \val{helpful} 0.02; Llama 3.3 70B at 0.94 and 0.06;
Qwen 3 235B at \val{helpful} 0.06), three in solo chat (Gemma 3 27B 0.95,
Gemma 3 12B 0.94, Qwen 3 32B 0.97, all \val{helpful}), and two in solo forced
choice (GPT-OSS models at \val{helpful} 0.06 and 0.09). Nulls involving those
specific cells are not evidence of absence --- there was nowhere to move. The
remaining 110 cells had room, so the stake and steering nulls are not
ceiling artefacts in general, but any per-model claim touching the ten listed
cells should be read as uninformative rather than negative.

\section{What the game draws out}

Pulling the results together, the game does not simply amplify or attenuate what
a model does alone. It changes what the model treats the question as being.

\paragraph{Solo elicitation reads as advice; game elicitation reads as action.}
Alone --- especially in chat --- models behave as though the task is to serve
the person in front of them, and helpfulness wins overwhelmingly. Seated in a
game, the same models behave as though the task is to avoid contributing to a
bad joint outcome, and harmlessness wins. The counterpart makes the
consequences of the choice feel external rather than conversational.

\paragraph{The mechanism is presence, not strategy.}
If the game were eliciting strategic reasoning, the repeated framing should
matter. It does not (Table~\ref{tab:horizon}). What moves preferences is that
someone else is also deciding.

\paragraph{Models converge under company.}
Between-model spread shrinks in the game. Idiosyncratic dispositions that show
up in solo evaluation are partly washed out when the model is one of two agents,
which means solo benchmarks may overstate how much models differ in deployment
settings that resemble games.

\paragraph{The steerable surface is the format, not the prompt.}
Stake framings and an HHH system prompt --- the levers one would naturally reach
for --- moved almost nothing, while changing forced choice to free text moved
helpfulness by up to $0.79$. If these preferences are to be controlled, the
evidence here points at how the question is posed rather than at what the system
prompt says.

\section{Limitations}
\label{sec:limits}

\begin{enumerate}\itemsep3pt
\item \textbf{Disjoint corpora.} Solo and game scenarios share no
      \texttt{scenario\_id}. The domain effect is a between-corpus contrast, and
      some of it may reflect differences in what the generator produced for the
      two formats rather than the presence of a counterpart. The horizon
      decomposition (Section~\ref{tab:horizon}) is the strongest evidence
      against a purely corpus-driven explanation, since solo, single-round and
      first-round conditions differ in framing while single-round and
      first-round share a corpus --- but a same-scenario design would settle it
      and we did not run one.
\item \textbf{One structural cell.} All games are two-player, two-action,
      simultaneous. Nothing here speaks to larger games, asymmetric action
      menus, or sequential moves.
\item \textbf{Judge dependence.} Free-text conditions in both domains are scored
      by a single judge model. A judge with different thresholds would shift the
      free-text levels, though the domain contrast is judge-matched on both
      sides.
\item \textbf{Refusals are informative and excluded.} GPT-OSS models declined a
      material fraction of solo forced-choice items. Their remaining rates
      describe an easier subset than their peers' rates do.
\item \textbf{Two models are incomplete.} Qwen 3.5 122B reached only 2 of 36
      game cells before a gateway failure and is excluded from the tables here.
      GPT-OSS Safeguard 20B was quarantined from the results tree during the run
      and is likewise absent.
\item \textbf{Annotative payoffs.} The payoff tensors attached to each game are
      reference annotations for economic analysis, not ground-truth utilities,
      and no result above depends on them.
\end{enumerate}
