# Data

Both corpora were generated by Claude Sonnet 5 and filtered by a GPT-5.6 Luna judge. All scenarios are synthetic.

| Path | Contents |
| --- | --- |
| `HHH_new_paper_bothAI_anthropic_batch_20260826_01/claude-sonnet-5_games.csv` | Two-player corpus: 503 scenarios, of which 117 have `keep_scenario` true. `game_spec` holds the full scenario as JSON (players, roles, actions, value tags, outcomes, payoff annotations) |
| `.../games/claude-sonnet-5_game_prompts.json` | Generation prompts |
| `.../games/open_prompts_balanced50_paid-gpt-5.6-luna.json` | Cached opening messages, counterpart not named (open-undisclosed) |
| `.../games/open_prompts_balanced50_counterpart_paid-gpt-5.6-luna.json` | Cached opening messages, counterpart named (open-disclosed) |
| `HHH_new_solo_20260826_01/claude-sonnet-5.csv` | Single-agent corpus in ConflictScope's schema: 1,187 scenarios, of which 162 are kept |

The evaluated set is 150 scenario-seats (50 per value pair) from 102 kept scenarios, chosen by hash rank under a fixed seed; `pair_limit: 50` in the configs repeats the selection.

Local directory prefixes in recorded run arguments inside `game_spec` were removed for release. Nothing else was edited.

ConflictScope's own datasets are not copied here; see <https://github.com/andyjliu/conflictscope>.
